# collision-avoidance-simulation-demo
3D Spatial Collision Simulator  A real-time collision avoidance prototype that tracks the position, speed, and rotation of two iPhones in 3D space.  This system utilizes native iOS sensors to capture high-frequency spatial telemetry, streams the data over WebSockets via a lightweight local relay server, and visualizes the physical devices in a web interface that calculates bounding-box intersections to trigger UI proximity warnings.  Architecture & Tech Stack  Clients (Sensors): iOS / Swift (CoreMotion, CoreLocation, URLSessionWebSocketTask)  Relay Server: Node.js (ws library)  Frontend (Simulation): Vanilla JavaScript / Three.js  Prerequisites  Hardware: 1 Mac laptop (for hosting and frontend UI) and 2 iPhones (for sensor data).  Network: All devices must be connected to the same local Wi-Fi network.  Software:  Node.js installed on your Mac.  Xcode installed on your Mac.  Apple Developer Account (a free account works for local deployment).  Setup Instructions  1. Find Your Local IP Address  Before starting, you need the local IP address of your Mac to allow the iPhones to connect.  Open your Mac's Terminal.  Run the command: ipconfig getifaddr en0 (or check Network Settings).  Note this IP address (e.g., 192.168.1.50).  2. Node.js Relay Server Setup  This server accepts WebSocket connections from the phones and broadcasts them to the browser.  Open your terminal and create a new directory for your project:  mkdir collision-simulator cd collision-simulator   Initialize a new Node project and install the ws (WebSocket) library:  npm init -y npm install ws   Create a server.js file and add your WebSocket relay code.  Run the server:  node server.js   The server should now be listening on a specific port (e.g., 8080).  3. Frontend (Three.js) Setup  The frontend simply connects to the local Node.js server and visualizes the data.  Inside your collision-simulator folder, create an index.html file.  Include the Three.js library via CDN (e.g., <script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>).  Add your JavaScript logic to connect a WebSocket to ws://localhost:8080 and update your 3D meshes based on the incoming data stream.  Open the index.html file in your browser to view the simulation space.  4. iOS Client Setup  The iOS app reads sensor data and pushes it to the server.  Open Xcode and create a new iOS App project (Swift/Storyboard or SwiftUI).  Permissions: Open your Info.plist and add the following keys to allow network and sensor access:  Privacy - Local Network Usage Description  Privacy - Motion Usage Description  Privacy - Location When In Use Usage Description  In your Swift code, set up CMMotionManager to poll at a high frequency (e.g., 60Hz).  Point your URLSessionWebSocketTask to your Mac's local IP address (e.g., ws://192.168.1.50:8080).  Connect your iPhones to your Mac via USB, select them as the run destination in Xcode, and build/run the app on both devices.  Usage  Ensure the Node server is running.  Open the frontend index.html in your browser.  Launch the app on both iPhones.  Move the iPhones in physical space. You should see two 3D boxes moving and rotating in your browser in real-time. Bring the phones close together to trigger the collision warning UI on your screen.
